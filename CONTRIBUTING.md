# Contributing to Home IO Control

The full contributor guide lives in [docs/contributing.md](docs/contributing.md): hardware and
device testing, how to report an unsupported device, and pull requests. If you want to build the
code, [docs/development-setup.md](docs/development-setup.md) has the toolchain, the test targets
and the flash commands.

The most useful contributions are hardware validation and real-world device reports — including
negative ones. If your device or board is not in
[docs/supported-devices.md](docs/supported-devices.md), a report either way moves it forward.

Open issues here: [GitHub Issues](https://github.com/laberning/home_io_control/issues).
